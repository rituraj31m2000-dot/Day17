# Firewall Fundamentals – Conceptual Firewall Policy

## Objective
Understand how firewalls filter network traffic and design a simple
conceptual firewall policy.

## Approach
1. Studied what a firewall is and where it sits (network edge / host).
2. Compared packet filtering, stateful inspection and proxy firewalls.
3. Classified traffic into allowed, denied and logged categories.
4. Wrote ordered rules using the default-deny principle.
5. Documented the policy in Google Docs.

## Outcome
A conceptual firewall policy with ordered rules, a default-deny
stance, and logging for denied traffic.

## Tools
Google Docs

## Files
- firewall-policy.md: the firewall policy
- report.md: task report

## Key Learnings
- Default deny is safer than default allow.
- Rule order matters: the first match wins.
- Stateful firewalls track connections and allow return traffic automatically.
